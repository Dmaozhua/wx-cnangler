一、全局启动加载界面（小程序初始化）
实现方案：
使用 wx.showLoading API
在 app.js 的 onLaunch 或 onShow 生命周期中显示加载动画：

javascript
// app.js
App({
  onLaunch() {
    wx.showLoading({
      title: '加载中...',
      mask: true // 防止触摸穿透
    });

    // 模拟初始化逻辑（替换为实际异步操作）
    setTimeout(() => {
      wx.hideLoading(); // 初始化完成后关闭
    }, 2000);
  }
});
自定义全局加载组件

创建组件 /components/loading（含 WXML/WXSS/JS）

在 app.json 中全局注册：

json
{
  "usingComponents": {
    "global-loading": "/components/loading"
  }
}
在 app.js 控制状态：

javascript
// app.js
App({
  globalData: {
    isLoading: true // 全局加载状态
  },
  onLaunch() {
    // 执行初始化逻辑...
    // 完成后设置：getApp().globalData.isLoading = false
  }
});
在首页 index.wxml 中使用：

html
<block wx:if="{{isLoading}}">
  <global-loading />
</block>
二、页面级资源加载动画
实现方案：
页面内使用 wx.showLoading
在页面 onLoad 或 onReady 中触发：

javascript
Page({
  onLoad() {
    wx.showLoading({ title: '加载资源...' });
    this.downloadResources().then(() => {
      wx.hideLoading();
    });
  },
  downloadResources() {
    return new Promise((resolve) => {
      // 实际下载逻辑（wx.downloadFile等）
      setTimeout(resolve, 1500);
    });
  }
});
结合骨架屏（Skeleton Screen）
在加载数据前显示骨架屏提升体验：

html
<!-- page.wxml -->
<view wx:if="{{!isDataReady}}">
  <!-- 骨架屏内容 -->
</view>
<view wx:else>
  <!-- 实际页面内容 -->
</view>
三、关键注意事项
加载超时处理
设置超时时间（如 10 秒），超时后提示用户：

javascript
let timer = setTimeout(() => {
  wx.hideLoading();
  wx.showToast({ title: '加载超时', icon: 'error' });
}, 10000);

// 加载完成后清除定时器
clearTimeout(timer);
网络异常处理
捕获下载错误并反馈：

javascript
wx.downloadFile({
  url: 'https://example.com/resource',
  success: (res) => { /* ... */ },
  fail: (err) => {
    wx.hideLoading();
    wx.showToast({ title: '下载失败', icon: 'none' });
  }
});
性能优化

使用 本地缓存（wx.setStorageSync）减少重复下载

分步加载：优先加载首屏必要资源，非关键资源延后

大文件使用 分包下载（通过 subpackages 配置）

动画设计原则

保持动画简洁（建议 1-2 秒）

提供明确的进度反馈（如进度条）

避免阻塞用户操作（mask: true 防止误触）

全局与页面加载的协调
若全局加载未完成，页面级加载应继承状态，避免动画叠加。

四、代码优化示例
javascript
// utils/loading.js
let loadingCount = 0;

export const showLoading = (title = '加载中') => {
  if (loadingCount === 0) {
    wx.showLoading({ title, mask: true });
  }
  loadingCount++;
};

export const hideLoading = () => {
  loadingCount--;
  if (loadingCount <= 0) {
    wx.hideLoading();
    loadingCount = 0;
  }
};

// 页面中使用
import { showLoading, hideLoading } from '../../utils/loading';

Page({
  onLoad() {
    showLoading();
    fetchData().then(hideLoading).catch(hideLoading);
  }
});
