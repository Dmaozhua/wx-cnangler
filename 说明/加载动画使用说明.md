# 小程序加载动画使用说明

本文档详细说明了小程序中新增的加载动画功能的使用方法。

## 功能概述

小程序现在支持两种类型的加载动画：
1. **全局加载动画** - 小程序启动时显示
2. **页面级加载动画** - 页面资源加载时显示

## 一、全局加载动画

### 实现原理
- 使用 `loadingdemo` 组件作为加载动画
- 在 `app.js` 中管理全局加载状态
- 在首页 `home.wxml` 中显示加载动画

### 配置说明

#### 1. 全局组件注册
在 `app.json` 中已注册全局组件：
```json
{
  "usingComponents": {
    "global-loading": "/components/loadingdemo/loadingdemo"
  }
}
```

#### 2. 全局状态管理
在 `app.js` 的 `globalData` 中：
```javascript
globalData: {
  isGlobalLoading: true,     // 全局加载状态
  loadingText: '正在初始化...' // 加载文本
}
```

#### 3. 自动隐藏机制
在 `app.js` 的 `onLaunch` 方法中，初始化完成后自动隐藏：
```javascript
setTimeout(() => {
  this.globalData.isGlobalLoading = false
  console.log('全局初始化完成，隐藏加载动画')
}, 2000)
```

### 使用方法

在需要显示全局加载动画的页面（如首页）的 WXML 中添加：
```xml
<!-- 全局加载动画 -->
<global-loading wx:if="{{isGlobalLoading}}" show="{{isGlobalLoading}}" text="{{loadingText}}" />

<!-- 页面内容，只有在不加载时才显示 -->
<view wx:if="{{!isGlobalLoading}}">
  <!-- 页面内容 -->
</view>
```

在页面的 JS 文件中同步全局状态：
```javascript
data: {
  isGlobalLoading: true,
  loadingText: '正在初始化...'
},

onLoad() {
  // 同步全局加载状态
  const app = getApp()
  this.setData({
    isGlobalLoading: app.globalData.isGlobalLoading,
    loadingText: app.globalData.loadingText
  })
  
  // 监听全局加载状态变化
  this.checkGlobalLoadingStatus()
},

// 监听全局加载状态变化
checkGlobalLoadingStatus() {
  const app = getApp()
  const checkInterval = setInterval(() => {
    if (!app.globalData.isGlobalLoading) {
      this.setData({
        isGlobalLoading: false
      })
      clearInterval(checkInterval)
    }
  }, 100)
}
```

## 二、页面级加载动画

### 实现原理
- 使用同样的 `loadingdemo` 组件
- 在页面级别管理加载状态
- 提供工具函数简化使用

### 工具函数

已创建 `utils/loading.js` 工具文件，提供以下函数：

#### 1. 基础加载动画
```javascript
import { showLoading, hideLoading } from '../../utils/loading'

// 显示加载动画
showLoading('加载中...', true)

// 隐藏加载动画
hideLoading()
```

#### 2. 页面级加载组件
```javascript
import { showPageLoading, hidePageLoading } from '../../utils/loading'

// 显示页面级加载
showPageLoading(this, '正在加载数据...')

// 隐藏页面级加载
hidePageLoading(this)
```

#### 3. 带加载动画的资源下载
```javascript
import { downloadWithLoading } from '../../utils/loading'

downloadWithLoading('https://example.com/file.jpg', '下载图片中...')
  .then(res => {
    console.log('下载成功', res)
  })
  .catch(err => {
    console.error('下载失败', err)
  })
```

#### 4. 带加载动画的网络请求
```javascript
import { requestWithLoading } from '../../utils/loading'

requestWithLoading({
  url: 'https://api.example.com/data',
  method: 'GET'
}, '获取数据中...')
  .then(res => {
    console.log('请求成功', res)
  })
  .catch(err => {
    console.error('请求失败', err)
  })
```

### 页面级使用示例

#### 1. 在页面 WXML 中添加组件
```xml
<!-- 页面级加载动画 -->
<global-loading wx:if="{{pageLoading}}" show="{{pageLoading}}" text="{{pageLoadingText}}" />

<!-- 页面内容 -->
<view class="page-content">
  <!-- 页面内容 -->
</view>
```

#### 2. 在页面 JS 中管理状态
```javascript
data: {
  pageLoading: false,
  pageLoadingText: '加载中...'
},

onLoad() {
  // 显示加载动画
  this.setData({
    pageLoading: true,
    pageLoadingText: '正在初始化...'
  })
  
  // 模拟异步操作
  this.loadPageData().then(() => {
    // 隐藏加载动画
    this.setData({
      pageLoading: false
    })
  })
},

loadPageData() {
  return new Promise((resolve) => {
    // 模拟异步操作
    setTimeout(() => {
      resolve()
    }, 2000)
  })
}
```

## 三、loadingdemo 组件说明

### 组件属性
- `show` (Boolean): 是否显示加载动画
- `text` (String): 加载提示文字，默认为 "pushing pixels"

### 组件样式
- 深色背景 (#222)
- 彩色动画点
- 渐变动画效果
- 响应式设计

### 自定义样式
如需修改加载动画样式，可以编辑：
- `components/loadingdemo/loadingdemo.wxss` - 样式文件
- `components/loadingdemo/loadingdemo.wxml` - 结构文件

## 四、最佳实践

### 1. 超时处理
- 工具函数已内置 10 秒超时保护
- 建议为长时间操作设置合理的超时时间

### 2. 错误处理
- 使用工具函数时会自动处理网络错误
- 建议在 catch 中提供用户友好的错误提示

### 3. 性能优化
- 避免同时显示多个加载动画
- 工具函数已实现加载计数，防止重复显示

### 4. 用户体验
- 加载时间超过 1 秒时建议显示加载动画
- 提供有意义的加载提示文字
- 避免加载动画闪烁（过快显示和隐藏）

## 五、注意事项

1. **全局加载动画**只在小程序启动时显示一次
2. **页面级加载动画**可以在任何页面中使用
3. 确保在异步操作完成后正确隐藏加载动画
4. 工具函数已处理异常情况，但仍建议添加额外的错误处理
5. 加载动画会阻止用户交互，请合理使用
