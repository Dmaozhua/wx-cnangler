# Banner图片WebP格式支持说明

## 已完成的优化

1. 已修改首页代码，使banner组件支持WebP格式图片
2. 在`bannerList`数组中为每个banner项添加了`webpUrl`属性，指向WebP格式的图片
3. 修改了图片加载逻辑，优先加载WebP格式，不支持时自动降级到JPG格式
4. 更新了颜色提取逻辑，确保能正确处理WebP格式的图片

## WebP格式转换指南

要将现有的JPG图片转换为WebP格式，可以使用以下方法：

### 方法一：使用在线转换工具

1. 访问在线WebP转换工具，如：https://convertio.co/zh/jpg-webp/ 或 https://ezgif.com/jpg-to-webp
2. 上传JPG图片
3. 设置压缩质量（建议75-85%，平衡质量和文件大小）
4. 下载转换后的WebP文件
5. 将WebP文件放入`images/banner`目录，保持与原JPG文件相同的文件名，仅更改扩展名

### 方法二：使用图像处理软件

1. 使用Photoshop、GIMP等图像处理软件打开JPG图片
2. 选择「导出为WebP」或类似选项
3. 调整质量设置（建议75-85%）
4. 保存到`images/banner`目录

## 文件命名规范

为确保系统正确识别和加载WebP图片，请遵循以下命名规范：

1. WebP文件应与对应的JPG文件同名，仅扩展名不同
   - 例如：`1.jpg` → `1.webp`
2. 将所有WebP文件放在与JPG文件相同的目录中（`images/banner/`）

## 性能优势

采用WebP格式可带来以下优势：

1. **文件体积减小**：相比JPG，WebP通常可减小25-35%的文件大小，同时保持相似的图像质量
2. **加载速度提升**：更小的文件体积意味着更快的加载速度，特别是在移动网络环境下
3. **流量节省**：减少用户流量消耗，提升用户体验

## 兼容性处理

已实现的代码已包含兼容性处理：

1. 对于支持WebP的设备，将自动加载WebP格式图片
2. 对于不支持WebP的设备，将自动降级使用JPG格式图片
3. 无需额外配置，系统会自动选择最佳格式
